# punto-rs

*Keyboard layout corrector daemon for Linux/Wayland: typed `ghbdtn` instead of
`привет`? Hit a hotkey — the word is retyped in the right layout. A Punto
Switcher / Easy Switcher alternative built on evdev/uinput, layout-agnostic by
design (works with any pair of layouts). Docs below are in Russian.*

Исправление раскладки уже набранного текста для Linux/Wayland — замена Punto
Switcher и Easy Switcher. Набрал `ghbdtn` вместо `привет`, нажал Insert —
слово перенабирается в правильной раскладке.

## Как это работает

Демон хранит не символы, а **скан-коды** нажатых клавиш. Чтобы исправить
раскладку, достаточно стереть набранное, переключить раскладку системной
комбинацией и переиграть те же самые физические клавиши — система сама
отдаст буквы другого алфавита.

Ключевое отличие от Easy Switcher: клавиатура **не перехватывается**
(`EVIOCGRAB` не вызывается). Easy Switcher забирал устройство себе и
переизлучал каждое нажатие — на этом он терял буквы при быстром наборе.
Здесь чтение пассивное: обычный набор идёт мимо демона и портиться не может.

Плата за это — горячая клавиша долетает и до активного приложения. Поэтому
её стоит выбирать безвредной: Pause/Break не делает ничего нигде, а вот
Insert в редакторах переключает режим замены.

## Сборка

```sh
cargo build --release
```

## Установка

```sh
sudo install -Dm755 target/release/punto-rs /usr/local/bin/punto-rs
sudo install -Dm644 config/punto-rs.conf   /etc/punto-rs/config.conf
sudo install -Dm644 systemd/punto-rs.service /etc/systemd/system/punto-rs.service
sudo systemctl daemon-reload
sudo systemctl enable --now punto-rs
```

Права root нужны для чтения `/dev/input/*` и создания виртуальной клавиатуры
через `/dev/uinput`.

## Использование

| Действие | Клавиши |
|---|---|
| Исправить последнее слово | `Insert` |
| Исправить всю фразу | `Shift+Insert` |

Буфер сбрасывается на `Enter`, на любой навигации (стрелки, `Home`, `Delete`)
и на любом сочетании с `Ctrl`/`Alt`/`Super` — то есть везде, где накопленное
перестаёт соответствовать тексту на экране.

## Настройка

Конфиг — `/etc/punto-rs/config.conf`, формат `ключ=значение`.

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `hotkey` | `insert` | клавиша исправления: имя или скан-код |
| `layout-switch` | `super+space` | системная комбинация смены раскладки |
| `key-delay` | `6` | пауза между нажатиями при переигрывании, мс |
| `post-backspace-delay` | `20` | пауза после стирания, мс |
| `switch-delay` | `120` | пауза после смены раскладки, мс |
| `devices` | пусто | клавиатуры по именам; пусто — автоопределение |
| `max-strokes` | `512` | предел буфера |

Клавиши задаются именем (`insert`, `pause`, `scrolllock`, `capslock`, `menu`,
`rightctrl`, `f1`…`f12` и другие) либо скан-кодом из `input-event-codes.h`.

Список устройств: `sudo punto-rs --list-devices`.
Скан-коды клавиш: `sudo showkey`.

## Тесты

```sh
cargo test                                          # юнит-тесты
cargo build --release --example e2e
sudo target/release/examples/e2e                    # сквозной, при работающем сервисе
```

Сквозной тест создаёт виртуальную клавиатуру, печатает на ней слово не в той
раскладке, жмёт горячую клавишу и проверяет по выходному устройству демона,
что во время набора тот молчал, а по нажатию стёр и перенабрал ровно то, что
нужно. Внимание: события уходят в живую сессию.

## Диагностика

```sh
systemctl status punto-rs
journalctl -u punto-rs -f
sudo punto-rs -v -c /etc/punto-rs/config.conf   # с остановленным сервисом
```

Первые буквы выходят в старой раскладке — увеличьте `switch-delay`.
Ничего не происходит — проверьте, что `layout-switch` совпадает с реальной
комбинацией смены раскладки в системных настройках.

## Ограничения

- Раскладка переключается инжектом системной комбинации, поэтому она должна
  быть настроена в самой системе и переключать ровно между двумя раскладками.
- Демон не видит текст на экране: если править курсором в середине строки,
  буфер и экран разойдутся. Такие случаи гасятся сбросом буфера на навигации.
